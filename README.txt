Bansal Drug Private Limited — Website Concept
================================================

Files:
- index.html — page structure
- style.css  — complete visual design and responsive layout
- script.js  — loading screen, mobile menu, scroll reveals, product filters and demo actions
- assets/bansal-drug-logo.png — generated Bansal Drug logo used in the concept

How to view:
1. Keep all files in the same folder structure.
2. Open index.html in a modern browser.
3. For the best demo, use Chrome/Edge at desktop width and then check mobile responsive mode.
